# Modulararbeit Webseiten-Projekt

## Projektbeschriebung
Dieses Projekt ist eine interaktive CV-Webseite. Es demonstriert die in IN251 erlernten Technologien.

## Verwendete Technologien
- **HTML5 & CSS3:** Für Semantik und ein responsives Grid-Layout (Mobile First).
- **JavaScript:** - Login-Redirection (Workaround gemäss PDF)
    - Interaktives Gadget (Canvas Kreis-Generator nach dem IPO-Prinzip)
- **Git & GitLab:** Für die Versionskontrolle und das Deployment (GitLab Pages).

## Wie funktioniert das Login?
Gemäss der Vorgabe im PDF gibt es keine Serverseite. Das Login funktioniert über eine Redirection.
**Das Passwort lautet:** `Start2026`
Durch die Eingabe wird der Nutzer auf `Start2026.html` weitergeleitet. Die Seite ist mit `<meta name="robots" content="noindex">` vor Suchmaschinen geschützt.
